---

## 🌟 Key Features

- **Signature "Physics in Motion" Visual Identity**: Multi-tiered orbital rings, floating scientific equations, and responsive particle canvas.
- **Physics Visual Lab**: 6 interactive HTML5 Canvas simulations (Projectile Motion, Simple Pendulum/SHM, Wave Superposition, Satellite Orbits, Lorentz Deflection, Ideal Gas Kinetic Theory) with real-time parameter controls and live calculations.
- **Handwritten Notes Showcase**: High-resolution authentic lecture notes and derivations authored for intermediate college students.
- **Physics Universe (Curriculum Explorer)**: 12 comprehensive modules detailing governing laws and Student Learning Outcomes (SLOs).
- **Student Hub ("For My Students")**: Quick-access formula reference sheets, solved numericals, and board examination strategies.
- **Global Search Command Palette (`Ctrl+K`)**: Instant search across all topics, notes, formulas, and resources.
- **Theme Switcher**: Dark Mode and Luxury Butter Cream Light Mode.
- **SEO & Structured Data**: Built-in Schema.org JSON-LD graph, OpenGraph tags, XML sitemap, and robots.txt.
